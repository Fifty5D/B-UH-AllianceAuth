# B-UH Moon Tax

Source for the private B-UH Alliance Auth Moon Tax application.

The package implements extraction-period billing, preserved mining evidence,
payment review, account and character billing modes, exemptions, reversible
adjustments, and permission-aware member/director views.

Compatibility and exact release pins live in `../../platform/compatibility.toml`.
Build and test this package through the repository workflows; do not edit a
published wheel or an existing release bundle.
